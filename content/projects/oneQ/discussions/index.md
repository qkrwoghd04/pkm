> [!summary]
> 원큐파트너스와 관련해 중요한 논의가 있었던 날마다 `YYYY-MM-DD.md` 파일 하나를 만들고, 출처별 내용을 같은 날짜 안에 이어서 기록한다.

## 기록 규칙

- 파일명은 `YYYY-MM-DD.md`만 사용한다.
- 하루에 파일 하나만 만들고, 같은 날의 내용을 해당 파일에 계속 추가한다.
- 논의 출처는 `회의`, `구두 논의`, `Slack 논의` 세 범주로 나눈다.
- 해당 날짜에 발생하지 않은 출처 섹션은 만들지 않는다.
- 합의된 내용은 `결정`, 실행할 내용은 `후속 작업`, 아직 열린 내용은 `미결 사항`으로 구분한다.
- 고객 정보, 계정 식별자, 내부 URL, 원본 대화 전문은 옮기지 않고 필요한 맥락만 요약한다.
