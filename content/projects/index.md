> [!summary]
> 프로젝트별 현재 맥락과 재사용 가능한 경험을 모은 지식 지도다. 현재 코드와 각 저장소의 문서가 PKM보다 우선한다.

## 프로젝트

- [[oneq-partners/index|원큐파트너스]] — 다자간 견적 중개 프로젝트의 개요, 경력 정리, 트러블슈팅 기록

## 사용 원칙

- 프로젝트 문서는 해당 프로젝트의 맥락과 결정, 요구사항, 운영 경험을 설명한다.
- 여러 프로젝트에서 반복되는 교훈은 추후 `patterns/`로 일반화한다.
- `draft` 상태의 요구사항과 시나리오는 확정 사실로 사용하지 않는다.
