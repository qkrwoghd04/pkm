> 코드와 용어는 요구사항·화면·테스트·결정 사이의 추적 기준이다. 코드는 발급 후 이름이 바뀌어도 재사용하지 않는다.

## 도메인 코드

| 코드 | 도메인      | 검색 키워드                                   | 적용 범위                        |
| ---- | ----------- | --------------------------------------------- | -------------------------------- |
| CM   | 공통        | 인증, 인가, 권한, 상태, 알림, 감사            | 전 도메인 공통 규칙              |
| SP   | 영업 파트너 | 파트너 신청, 추천코드, QR, 포털               | 파트너와 고객 유입               |
| BC   | 업종        | 카테고리, 세부 서비스, 상담 폼                | 상담 대상 업종 기준정보          |
| CU   | 고객        | 고객 식별, 비회원, 휴대폰 인증                | 고객 계정과 신청 이력 연결       |
| CO   | 상담        | 서비스 신청, 상담, 요구사항                   | 고객 요청 수집·보완              |
| QT   | 견적        | 견적 요청, 방문 견적, 온라인 견적, 비교, 선택 | 공급업체 매칭과 견적             |
| SU   | 공급업체    | 공급업체, 공급업체 사용자, 진행 확인          | 공급업체 기준정보·계정·응답      |
| CT   | 계약        | 계약, 계약서                                  | V1 제외. 과거 이력 식별에만 사용 |

## 식별자 형식

| 종류            | 기본 형식          | 세부 그룹 포함 형식     | 예                         |
| --------------- | ------------------ | ----------------------- | -------------------------- |
| 기능 요구사항   | `FR-[도메인]-001`  | `FR-[도메인]-[그룹]001` | `FR-QT-001`, `FR-QT-CP001` |
| 기능            | `F-[도메인]-001`   | `F-[도메인]-[그룹]001`  | `F-QT-001`, `F-QT-CP001`   |
| 비기능 요구사항 | `NFR-[분류]-001`   | `NFR-[분류]-[그룹]001`  | `NFR-SEC-001`              |
| 사용자 시나리오 | `SCN-[도메인]-001` | 해당 없음               | `SCN-QT-001`               |

## 발급 규칙

- 영문 대문자, 숫자, 하이픈만 사용한다.
- FR·F·NFR 순번은 세 자리로 쓴다.
- 세부 그룹은 독립된 업무·품질 묶음이 둘 이상일 때만 사용한다.
- 신규 세부 그룹은 용어 기준에 먼저 등록한다.
- 발급된 코드는 이름 변경 후에도 바꾸거나 재사용하지 않는다.
- 폐기 코드는 삭제하지 않고 `deprecated` 또는 `범위 제외`로 남긴다.
- 신규 V1 코드에 `CT`를 사용하지 않는다.

## 주요 세부 그룹

- SP: `AP` 신청, `AG` 계약, `QR` QR, `PT` 파트너 포털
- BC: `SS` 세부 서비스, `FM` 상담 폼
- CU: `ID` 고객 식별, `PV` 휴대폰 인증
- CO: `RQ` 신청, `CS` 상담, `RM` 요구사항
- QT: `RQ` 견적 요청, `OQ` 방문 견적, `NQ` 온라인 견적, `CP` 비교·선택, `RJ` 거절·철회
- SU: `US` 공급업체 사용자, `CN` 최종 진행 확인

## NFR 분류

`PERF` 성능, `AVL` 가용성, `SEC` 보안, `PRIV` 개인정보, `COMP` 호환성, `REL` 신뢰성, `REC` 백업·복구, `OPS` 운영성 등을 사용한다.

## 추적 규칙

- 화면 명세는 충족하는 FR과 구현 F 또는 정책 코드를 참조한다.
- 테스트 시나리오는 검증 대상 FR·F·정책·상태·예외 코드를 참조한다.
- 상태 정의는 관련 FR 또는 F를 연결한다.
