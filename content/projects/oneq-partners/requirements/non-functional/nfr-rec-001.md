- 분류·세부그룹: REC / 해당 없음

- 담당자: 개발·인프라 담당자(구현) / 프로젝트 책임자(검수)

#### 품질 요구사항

시스템은 운영 데이터 손상·삭제·배포 오류가 발생했을 때 정해진 복구 목표 안에서 최근 백업으로 핵심 업무 데이터를 복구할 수 있어야 합니다.

#### 목적·영향

신청·견적·선택 결과가 복구되지 않으면 핵심 MVP 업무를 재개할 수 없으므로, 제한된 운영 리소스로 실행 가능한 최소 백업·복구 기준을 정합니다.

#### 적용 조건

- 환경: 운영 환경 필수, 복구 검증은 비운영 환경
- 적용 시점: 운영 데이터 변경 상시, 데이터 손상·삭제·배포 오류 발생 시
- 제외 조건: 다중 리전 재해복구·실시간 복제·정기 복구 훈련은 MVP 범위에서 제외

#### 기준 미충족·예외 처리

- 미충족 시 처리: 백업 실패 알림 확인 후 재실행 또는 설정 수정. 복구 시험 실패 시 운영 배포 차단
- 예외 허용 조건: 관리형 서비스 제약으로 동일한 RPO·RTO를 다른 방식으로 충족하고 근거를 제출한 경우
- 예외 승인 주체·기한: 프로젝트 책임자 / 운영 배포 전

#### 검증·수용 기준

- Given: 운영과 동일한 스키마의 비운영 환경과 최신 백업이 준비되어 있음
- When: 백업을 복원하고 신청·견적·선택 데이터와 파일 연결을 조회함
- Then: RPO·RTO 안에 핵심 데이터가 정상 조회되고 연결 누락이 없음
- 검증 근거: 자동 백업 설정 화면, 복구 시작·완료 기록, 복구 데이터 확인 결과
