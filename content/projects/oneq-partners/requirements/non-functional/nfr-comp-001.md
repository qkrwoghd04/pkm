#### 품질 요구사항

시스템은 확정된 최소 지원 OS·브라우저와 화면 크기에서 로그인부터 최종 확인까지 각 채널의 핵심 MVP 업무를 완료할 수 있어야 합니다.

#### 목적·영향

주요 사용 환경에서 인증·입력·업로드·조회·상태 변경이 막히는 문제를 출시 전에 발견하되, 제한된 리소스에 맞춰 최소 대표 환경만 검수합니다.

#### 적용 조건

- 환경: 검증·운영 환경
- 적용 시점: 개발 완료와 출시 전 회귀 검수
- 제외 조건: Internet Explorer, 태블릿 전용 화면, 전체 기기 조합, 명시한 최소 버전보다 낮은 환경

#### 기준 미충족·예외 처리

- 미충족 시 처리: 지원 환경에서 업무를 막는 레이아웃·입력·업로드·인증 오류는 출시 차단 결함으로 처리
- 예외 허용 조건: 해당 환경의 플랫폼 결함 또는 외부 SDK 미지원이며 대체 경로와 사용자 안내가 제공되는 경우
- 예외 승인 주체·기한: 프로젝트 책임자와 고객 담당자 공동 승인 / 운영 배포 전

#### 검증·수용 기준

- Given: 실제 iOS·Android 기기와 PC Chrome·Edge, 대표 사용자 계정이 준비되어 있음
- When: 각 채널에서 로그인·신청·견적·선택·최종 확인의 해당 핵심 경로를 수행함
- Then: 최소 지원 환경과 화면 크기에서 업무 차단 오류 없이 완료됨
- 검증 근거: 환경별 기기·OS·브라우저 버전과 결과가 기록된 체크리스트
