#### 품질 요구사항

시스템은 운영과 유사한 환경에서 동시 사용자 30명이 핵심 MVP 업무를 수행할 때 조회·등록·수정·상태 변경 요청의 95%를 3초 이내에 응답해야 합니다.

#### 목적·영향

핵심 업무의 지연으로 신청·견적·선택 흐름이 중단되거나 사용자가 중복 제출하지 않도록, 예상 사용량에 맞는 최소 응답 기준을 설정합니다.

#### 적용 조건

- 환경: 운영과 유사한 검증 환경
- 적용 시점: 로그인부터 최종 확인까지 핵심 E2E 경로 측정 시
- 제외 조건: 파일 자체 전송 시간, SMS·푸시 등 외부 사업자의 처리 완료 시간

#### 기준 미충족·예외 처리

- 미충족 시 처리: 기준 초과 단계의 쿼리·응답 데이터·불필요한 동기 처리를 우선 개선하고 동일 조건으로 재측정
- 예외 허용 조건: 외부 사업자 처리 또는 파일 전송처럼 제외 조건에 해당하고 사용자에게 진행 상태를 안내하는 경우
- 예외 승인 주체·기한: 프로젝트 책임자 / 운영 배포 전

#### 검증·수용 기준

- Given: 운영과 유사한 환경, 대표 데이터, 동시 사용자 30명 조건이 준비되어 있음
- When: 로그인 → 고객 신청 → 견적 요청 → 공급업체 응답 → 고객 선택 → 최종 확인 경로를 측정함
- Then: 핵심 조회·변경의 p95가 3초 이내이고 오류 조건에서는 5초 이내 처리 불가 여부와 재시도 안내가 제공됨
- 검증 근거: 단계별 응답시간 원본과 p95 집계 결과, 오류 안내 확인 결과
