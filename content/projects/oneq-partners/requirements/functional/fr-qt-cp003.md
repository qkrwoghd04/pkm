## 요구사항

고객은 공급업체의 최종 진행 가능 확인 전까지 허용된 상태에서 선택한 공급업체·견적을 변경하거나 취소할 수 있어야 한다.

## 배경·목적

고객의 공급업체·견적 선택 이후 최종 진행 가능 확인 전까지 변경·취소 가능한 시점과 관련 사용자에게 반영할 결과를 명확히 한다.

## 대상·범위

- 포함: 공급업체·견적 선택 변경·취소, 변경 이력, 공급업체·운영사 반영
- 제외: 공급업체의 최종 진행 가능 확인 이후 자동 변경, 계약·계약서 처리
- 적용 채널·환경: 고객 모바일 웹·앱, 원큐 운영사 PC 어드민 웹, 공급업체 모바일 웹

- 제외: 공급업체의 최종 진행 가능 확인 이후 자동 변경, 계약·계약서 처리
- 적용 채널·환경: 고객 모바일 웹·앱, 원큐 운영사 PC 어드민 웹, 공급업체 모바일 웹

## 조건·업무 흐름

- 사전 조건: 고객이 공급업체·견적을 선택했으나 공급업체의 최종 진행 가능 확인은 완료되지 않았다.
- 트리거: 고객이 기존 선택의 변경 또는 취소를 요청한다.

1. 시스템은 현재 상태가 변경·취소 가능한지 확인한다.
2. 허용되면 기존 선택을 해제하고 새 선택 또는 취소 결과를 저장한다.
3. 영향받는 공급업체와 운영사에 변경 결과를 반영한다.
4. 최종 진행 가능 확인 이후에는 자동 변경을 제한하고 운영사 문의를 안내한다.
