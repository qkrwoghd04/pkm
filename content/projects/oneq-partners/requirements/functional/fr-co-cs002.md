## 요구사항

원큐 운영사 관리자와 상담사는 접수된 상담 신청을 업무 큐에서 조회하고 담당자를 배정·재배정하며 처리 우선순위와 진행 상태를 관리할 수 있어야 한다.

## 배경·목적

상담사 배정 요구사항은 있으나 실제 어드민 운영에 필요한 미배정·지연·담당 업무 큐와 재배정 기능이 없다.

## 대상·범위

- 포함: 상담 신청 목록·상세, 미배정 큐, 담당자 배정·재배정, 상태·우선순위 필터
- 제외: 계약(CT) 도메인과 계약 이후 실제 이행
- 적용 채널·환경: 원큐 운영사 PC 어드민 웹

## 조건·업무 흐름

- 사전 조건: 고객의 상담 신청이 접수되었다.
- 트리거: 관리자 또는 상담사가 상담 업무 큐를 조회한다.

1. 시스템은 신청 상태·담당자·접수 시각 기준으로 업무 큐를 제공한다.
2. 관리자는 담당자를 배정하거나 재배정한다.
3. 상담사는 본인 담당 신청을 확인하고 상담을 시작한다.

## 대안·예외 흐름

| 발생 조건          | 업무 처리                               | 최종 결과   |
| ------------------ | --------------------------------------- | ----------- |
| 담당자 미배정      | 미배정 큐에 유지하고 관리자에게 표시    | 배정 대기   |
| 담당자 비활성·부재 | 재배정 대상임을 표시                    | 재배정 대기 |
| 중복 신청          | 중복 가능성을 표시하고 운영사 판단 요청 | 검토 대기   |

- Given: 상담 신청이 접수된 상태
- When: 운영자가 업무 큐를 조회하고 담당자를 배정
- Then: 신청의 담당자와 진행 상태가 저장되고 담당자별로 조회된다.
