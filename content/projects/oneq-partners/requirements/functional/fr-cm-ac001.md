## 요구사항

개발사가 생성한 최초 관리자는 다른 관리자와 상담사 계정을 생성·관리할 수 있어야 하며, 일반 관리자는 상담사 계정만 생성·관리할 수 있어야 한다. 상담사는 운영사 계정을 관리할 수 없어야 한다.

## 배경·목적

원큐 운영사 관리자와 상담사는 영업 파트너 승인, 공급업체 관리, 고객 상담, 견적 요청 등 여러 도메인의 업무를 수행한다. 권한 정책이 전제하는 운영사 계정과 역할의 생성·중지·인수인계 책임을 공통 요구사항으로 정의하여, 고객사가 개발사 의존 없이 일상적인 운영사 사용자 계정을 관리할 수 있게 한다.

## 대상·범위

- 포함: 개발사의 최초 관리자 계정 생성·수기 전달, 관리자·상담사 계정 생성, 역할 부여·변경, 계정 중지·재활성화, 최초 로그인 비밀번호 변경, 계정·역할·상태 변경 이력
- 포함: 고객사 확인 후 개발사가 수행하는 최초 관리자 계정 재설정 또는 신규 최초 관리자 지정
- 제외: 영업 파트너·고객·공급업체 계정, SSO, 조직·팀 관리, 세부 권한 커스터마이징, 다중 역할, 임시 권한
- 제외: 자동 계정 안내, 복수 최초 관리자, 시스템 화면 내 최초 관리자 권한 이전
- 적용 채널·환경: 원큐 운영사 PC 어드민 웹, 개발사 운영·인수인계 절차

## 조건·업무 흐름

- 사전 조건: 개발사가 고객사에서 지정한 사용자로 최초 관리자 계정을 생성한다.
- 트리거: 최초 관리자 또는 일반 관리자가 권한 범위 안에서 운영사 사용자 계정을 생성·변경하거나, 최초 관리자 복구가 필요해 고객사가 개발사에 요청한다.

1.  개발사는 최초 관리자 계정을 생성해 고객사에 수기로 전달한다.
2.  최초 관리자는 최초 로그인 후 초기 비밀번호를 변경한다.
3.  최초 관리자는 관리자 또는 상담사 계정을 생성하고 역할을 부여한다.
4.  일반 관리자는 상담사 계정만 생성·관리한다.
5.  생성된 계정 정보는 전화·수기 방식으로 대상 사용자에게 전달한다.
6.  관리자는 권한 범위 안에서 계정을 중지·재활성화하고 역할을 변경한다.
7.  시스템은 계정 생성, 역할 변경, 상태 변경의 처리자와 처리 시각을 기록한다.
8.  최초 관리자 접근이 불가능하면 고객사가 재설정 또는 신규 지정 대상을 확인해 개발사에 요청한다.
9.  개발사는 고객사의 요청·승인 근거를 확인한 뒤 기존 최초 관리자 계정을 재설정하거나 새로운 최초 관리자를 지정하고, 필요한 경우 기존 계정을 중지한다.
10. 개발사는 최초 관리자 복구·지정 대상, 처리자, 처리 시각과 요청·승인 근거를 기록한다.

## 기준 문서

- 정책·업무 규칙: 도메인별 정책, 고객사 확인 기반 최초 관리자 수동 복구 절차
- 상태: 상태 정의 — 운영사 계정 활성·중지 상태 후속 반영 필요
- 권한: 권한 정책
- 데이터:
  - 식별·관계: 운영사 사용자 ID, 운영사 계정 ID, 최초 관리자 지정 대상 계정 ID
  - 업무 입력·결과: 로그인 식별정보, 사용자명·연락처, 관리자·상담사 역할, 초기 접근 정보 전달 결과, 최초 관리자 복구·지정 요청 및 고객사 승인 근거
  - 상태·이력: 계정 활성·중지 상태, 최초 관리자·일반 관리자·상담사 권한 유형, 최초 비밀번호 변경 여부, 계정·역할·상태 변경 이력, 최초 관리자 재설정·지정 이력

## 수용 기준

- Given: 개발사가 생성한 최초 관리자로 로그인한 상태
- When: 관리자 또는 상담사 계정을 생성하고 역할을 부여
- Then: 계정이 생성되고 사용자는 부여된 역할에 허용된 기능과 데이터만 이용할 수 있다.
- Given: 일반 관리자로 로그인한 상태
- When: 상담사 계정을 생성·중지·재활성화하거나 관리자 계정을 생성·변경하려고 함
- Then: 상담사 계정 관리는 허용되고 관리자 계정 생성·변경은 차단된다.
- Given: 중지된 운영사 계정
- When: 해당 사용자가 로그인을 시도
- Then: 접근은 차단되지만 기존 업무 처리 이력은 유지된다.
- Given: 최초 관리자 퇴사·계정 분실·접근 불가가 발생하고 고객사가 복구 대상을 확인함
- When: 개발사가 요청·승인 근거를 확인해 계정을 재설정하거나 새로운 최초 관리자를 지정함
- Then: 지정된 최초 관리자가 관리자 계정을 관리할 수 있고 대상·처리자·처리 시각·근거가 기록된다.
