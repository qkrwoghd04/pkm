## 요구사항

공급업체는 견적 요청을 확인하고 24시간 이내에 거절·바로 견적·방문 견적 중 하나로 응답할 수 있어야 한다.

## 배경·목적

공급업체가 고객 요구사항을 검토하고 거절·바로 견적·방문 견적 의사를 제출한다.

## 대상·범위

- 포함: 위 요구사항을 달성하는 데 필요한 업무 결과와 사용자 흐름
- 제외: 화면·API·필드 수준의 구현 명세는 관련 기능(F) 문서에서 관리
- 적용 채널·환경: 공급업체 모바일 웹, 원큐 운영사 PC 어드민 웹

## 조건·업무 흐름

- 사전 조건: 공급업체에 유효한 견적 요청이 발송되어 응답 수집 중이다.
- 트리거: 공급업체가 견적 요청 상세를 확인한다.

1. 공급업체는 고객 요구사항을 조회한다.
2. 시공 의사가 없으면 거절 응답을 제출한다.
3. 시공 의사가 있으면 바로 견적 또는 방문 견적 희망을 선택한다.
4. 바로 견적을 선택하면 가격 견적을 제출한다.

- 업무 규칙: 응답은 견적 요청 발송 후 24시간 이내에 제출해야 한다.
- 업무 규칙: 응답 필드·수정 가능 여부는 미정이다.

## 대안·예외 흐름

| 발생 조건                              | 업무 처리                              | 최종 결과    |
| -------------------------------------- | -------------------------------------- | ------------ |
| 24시간 마감 후 제출은 허용하지 않는다. | 24시간 마감 후 제출은 허용하지 않는다. | 안내 후 종료 |

  - 상태·이력: 견적 응답 상태, 제출 시각, 응답 마감 시각

## 수용 기준

- Given: 공급업체에 유효한 견적 요청이 발송되어 응답 수집 중이다.
- When: 공급업체가 견적 요청 상세를 확인한다.
- Then: 공급업체 응답이 해당 견적 요청에 정확히 연결된다. 또한 거절·바로 견적·방문 견적 유형을 구분해 저장한다.
