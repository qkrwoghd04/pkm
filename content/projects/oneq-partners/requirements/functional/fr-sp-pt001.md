## 요구사항

영업 파트너는 인증 후 파트너 포털에 접근하고 본인의 역할과 데이터 범위에 허용된 메뉴만 이용할 수 있어야 한다.

## 배경·목적

영업 파트너의 포털 접근 권한과 데이터 범위를 명확히 하여 다른 파트너 또는 허용되지 않은 고객 정보가 노출되지 않도록 한다.

## 대상·범위

- 포함: 파트너 인증, 포털 접근, 본인 유입 고객 조회, 데이터 범위 제한
- 제외: 계약(CT) 도메인과 계약 이후 실제 이행
- 적용 채널·환경: 영업 파트너 포털

## 조건·업무 흐름

- 사전 조건: 영업 파트너가 승인 완료 상태이고 유효한 계정으로 로그인한다.
- 트리거: 파트너가 포털 메뉴 또는 보호 데이터에 접근한다.

1. 시스템은 로그인 계정의 파트너 상태와 권한을 확인한다.
2. 허용된 메뉴와 본인 귀속 데이터만 제공한다.
3. 권한 범위를 벗어난 접근은 차단하고 안내한다.

## 대안·예외 흐름

| 발생 조건                  | 업무 처리                             | 최종 결과 |
| -------------------------- | ------------------------------------- | --------- |
| 비활성·중지 계정           | 포털 접근을 차단하고 운영사 문의 안내 | 접근 차단 |
| 본인 유입 고객 없음        | 빈 상태와 안내 제공                   | 정상 조회 |
| 다른 파트너 고객 접근 시도 | 권한 검증 후 차단하고 로그 기록       | 접근 거부 |

## 기준 문서

- 정책·업무 규칙: 도메인별 정책
- 상태: 상태 정의
- 권한: 권한 정책
- 데이터:
  - 식별·관계: 영업 파트너 ID, 파트너 계정 ID, 추천코드, 귀속 고객 신청 ID
  - 업무 입력·결과: 역할·권한 범위, 허용 메뉴, 허용 데이터 범위
  - 상태·이력: 승인·활동 상태, 접근·차단 결과, 접근 시각

## 수용 기준

- Given: 승인 완료된 영업 파트너와 접근 권한이 없는 계정이 준비되어 있다.
- When: 각 계정이 파트너 포털과 보호 메뉴에 접근한다.
- Then: 승인된 파트너에게만 본인 역할과 귀속 범위의 메뉴·데이터가 제공되고 나머지 접근은 차단된다.

- When: 파트너가 포털에서 유입 고객을 조회
- Then: 본인 귀속 고객의 허용 정보만 제공되고 권한 위반 접근은 차단된다.
