## 요구사항

원큐 운영사 관리자는 등록 완료된 공급업체에 서비스 이용 계정을 발급할 수 있어야 하며, 공급업체는 발급된 계정으로 서비스를 이용할 수 있어야 한다.

## 배경·목적

등록 완료된 공급업체에 서비스 사용 계정을 발급한다.

## 대상·범위

- 포함: 위 요구사항을 달성하는 데 필요한 업무 결과와 사용자 흐름
- 제외: 화면·API·필드 수준의 구현 명세는 관련 기능(F) 문서에서 관리
- 적용 채널·환경: 원큐 운영사 PC 어드민 웹, 공급업체 모바일 웹

## 조건·업무 흐름

- 사전 조건: 공급업체가 등록 완료 상태이다.
- 트리거: 관리자가 계정 발급을 실행한다.

1. 시스템은 등록 완료 공급업체인지 확인한다.
2. 공급업체 계정을 생성하고 해당 공급업체 정보와 연결한다.
3. 계정 발급 완료 상태를 저장한다.

- 업무 규칙: 계정 필드·초기 비밀번호·전달 방식은 미정이다.
- 업무 규칙: 등록 완료 전에는 계정을 발급할 수 없다.

## 대안·예외 흐름

| 발생 조건      | 업무 처리                                        | 최종 결과   |
| -------------- | ------------------------------------------------ | ----------- |
| 계정 생성 실패 | 등록 완료 상태는 유지하고 재시도할 수 있게 한다. | 재시도 가능 |

## 기준 문서

- 정책·업무 규칙: 도메인별 정책
- 상태: 상태 정의
- 권한: 권한 정책
- 데이터:

  - 업무 입력·결과: 로그인 식별값, 발급 연락처, 초기 접근 정보 전달 결과
  - 상태·이력: 계정 발급 상태, 발급 시각, 발급자

## 수용 기준

- Given: 공급업체가 등록 완료 상태이다.
- When: 관리자가 계정 발급을 실행한다.
- Then: 발급 계정이 올바른 공급업체와 연결된다. 또한 발급 완료 공급업체가 로그인해 견적 요청을 확인할 수 있다.
