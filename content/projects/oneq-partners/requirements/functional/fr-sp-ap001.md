## 요구사항

영업 파트너 신청자는 사업자 정보를 제출하고 원큐 활동 파트너 승인을 요청할 수 있어야 한다.

## 배경·목적

영업 파트너가 사업자 정보를 제출하고 원큐 활동 파트너 승인을 요청한다.

## 대상·범위

- 포함: 위 요구사항을 달성하는 데 필요한 업무 결과와 사용자 흐름
- 제외: 화면·API·필드 수준의 구현 명세는 관련 기능(F) 문서에서 관리
- 적용 채널·환경: 영업 파트너 신청 웹

## 조건·업무 흐름

- 사전 조건: 영업 파트너가 회원가입을 시작한다.
- 트리거: 사업자 정보를 입력하고 파트너 신청을 제출한다.

1. 시스템은 입력된 사업자 정보로 기존 파트너 등록 여부를 확인한다.
2. 미등록 사업자이면 파트너 신청을 저장하고 승인 대기 상태로 전환한다.
3. 이미 등록된 사업자이면 등록된 파트너임을 안내하고 신규 신청을 만들지 않는다.

- 업무 규칙: 신청자는 본인의 신청만 조회할 수 있다.
- 업무 규칙: 승인 대기 중에는 신청 정보를 직접 수정할 수 없다.
- 업무 규칙: 상태·권한 기준: 상태 정의, 권한 정책

## 대안·예외 흐름

| ------------------------------------------------------ | ------------------------------------------------------ | ------------ |
| 기존 등록 사업자인 경우 신규 신청을 차단하고 안내한다. | 기존 등록 사업자인 경우 신규 신청을 차단하고 안내한다. | 처리 제한    |
| 필드 검증과 오류 문구는 미정이다.                      | 필드 검증과 오류 문구는 미정이다.                      | 안내 후 종료 |

## 기준 문서

- 정책·업무 규칙: 도메인별 정책
- 상태: 상태 정의
- 권한: 권한 정책
- 데이터:
  - 식별·관계: 영업 파트너 신청 ID, 중복 확인 대상 영업 파트너 ID
  - 업무 입력·결과: 신청자 연락처, 사업자번호, 상호, 대표자, 주소, 증빙자료, 동의 정보, 중복 확인 결과
  - 상태·이력: 제출 상태, 제출 시각, 신청 변경 이력

## 수용 기준

- Given: 영업 파트너가 회원가입을 시작한다.
- When: 사업자 정보를 입력하고 파트너 신청을 제출한다.
- Then: 미등록 사업자의 신청 건이 승인 대기 상태로 저장된다. 또한 중복 사업자는 신규 신청이 생성되지 않는다.
